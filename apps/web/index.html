How it works

Three moving parts. All yours.

01

The extension captures

A tiny Chrome extension saves what you clip straight to your browser — instantly, offline, private.

02

Your browser stores it

Everything lives in the extension on your machine — originals, text, search. No server, no account.

03

Your Claude Code enriches

A local agent hands each capture to your own Claude Code for OCR, tags and summaries — queued when it's off.

Self-hosted by design

Your second brain lives on your hardware.

No accounts, no third-party cloud, no one mining your reading history. Everything runs in your browser and your own Claude Code — the code is open. Install the extension, run the agent once, done.
