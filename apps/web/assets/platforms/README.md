# Platform icons

Chrome, App Store (iOS), and Google Play use the published Font Awesome Free 6.7.2 brand SVGs, downloaded from https://github.com/FortAwesome/Font-Awesome/tree/6.7.2/svgs/brands. Original SVGs and the upstream license are retained here. `icons.svg` combines their unchanged paths into a same-origin sprite consumed by the shared `PlatformIcon` component.
