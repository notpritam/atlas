## Proposed UX priorities

1. **Shorten first collection creation.** The current form presents name, slug, description, topics, collection type, visibility, contributor policy, approval and community rules together. Put name and audience first. Keep safe defaults, with optional details and advanced contribution settings disclosed when needed. Do not add a mandatory wizard for a simple personal collection.
2. **Make save destinations and publication status obvious.** Use consistent destination selection in capture details, the extension and collection pages. Show personal/group and public/private context, then a specific saved/pending confirmation with a route to the destination. Keep private annotations opt-in for sharing.
3. **Keep visitors in the collection journey.** Public Follow/Contribute currently links to generic login. Authentication should return to the intended collection safely, with the user confirming the action under the signed-in account.
4. **Manage people where they appear.** Changing a group member's role currently requires re-entering their email in the invitation form. Put role controls on each member row and distinguish pending invitations, accepted members and removal feedback.
5. **Clarify everyday organization.** Review how My library, folders, tags and shared collections relate. Ensure empty states and navigation explain the next useful action without adding more competing controls.

Start with the collection journey unless Pritam chooses another flow in the pending priority question. These are UX proposals, not new claims about plan entitlements or completed changes.
